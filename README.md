# FNP Sales Analysis Dashboard using Excel

## Project Overview
This project is an interactive Excel dashboard developed to analyze FNP sales performance, customer behavior, and revenue trends.

---

## Objectives
- Analyze sales performance
- Track revenue trends
- Identify top products
- Study customer spending behavior

---

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

---

## Dashboard Features
- Revenue by Occasion
- Revenue by Category
- Revenue by Month
- Revenue by Day
- Top Products by Revenue
- Top Cities by Revenue
